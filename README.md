Contem 30 comandos Linux importantes e relacionados a Bioinformática e Engenharia Biomédica.

##  1 COMANDO - ls
**Para que serve:** Ele verifica os arquivos e pastas de um diretório selecionado.
**Exemplo:**
```bash
ls -1 
Se voce precisar verificar uma pasta ou arquivos expecificos de um diretório
```
## 2 COMANDO - mkdir
**Para que serve:** Cria uma nova pasta.
**Exemplo:**
```bash
mkdir projetos 
Se Voce precisar criar uma pasta para guardar fotos ou arquivos importantes ele serve.
```
## 3 COMANDO - cat
**Para que serve:** Exibe o conteudo de algum arquivo direto no terminal
**Exemplo:**
```bash
cat texto.txt
Se voce tiver com preguiça de abrir a pasta ou algo  dá para só usar o terminal
```
## 4 COMANDO - cd
**Para que serve:** Faz com que voce possa explorar entre as pastas
**Exemplo:**
```bash
cd Documentos
Se voce tem muitas pastas de arquivos  entre eles trabalho/faculdade/jogos esse comando ajuda na navegação entre elas
```
## 5 COMANDO - top
**Para que serve:** Mostra os processos que estão sendo executados em tempo real
**Exemplo:**
```bash
top
Se voce sentir que seu pc está consumindo muita memoria esse comando ajuda a voce monitorar quais estão pesando mais
```
## 6 COMANDO - date
**Para que serve:** Mostra a data e a hora do sistema
**Exemplo:**
```bash
date
Está com preguiça de ver a hora no celular esse comando faz isso
```
## 7 COMANDO - mv
**Para que serve:** Serve para mover arquivos e renomear eles
**Exemplo:**
```bash
mv arquivo.txt pasta/
O nome da pasta está muito grande ou quer trocar ele de lugar esse comando faz isso
```
## 8 COMANDO - chmod
**Para que serve:** Muda permissões de arquivos
**Exemplo:**
```bash
chmod 777 arquivo.txt
Algum programa precisa de alguma permissão expecifica com esse comando isso é possivel
```
## 9 COMANDO - less
**Para que serve:** Faz com que arquivos muito grandes sejam vistos em partes 
**Exemplo:**
```bash
less arquivo.txt
Tem algum arquivo de texto muito grande e só quer alguma parte expecifica, use esse comando
```
## 10 COMANDO - pwd
**Para que serve:** Mostra o caminho da pasta 
**Exemplo:**
```bash
pwd
Permite que voce saiba onde ela foi criado e que pastas voce precisa abrir para chegar nela
```
## 11 COMANDO - clear
**Para que serve:** Limpa o terminal
**Exemplo:**
```bash
clear
Faz com que o terminal seja limpo
```
## 12 COMANDO - head
**Para que serve:** Vai te levar para as primeiras linhas do arquivo
**Exemplo:**
```bash
head arquivo.txt
Voce criou um arquivo de texto muito grande e quer o ler desde o inicio ele te ajuda nisso
```
## 13 COMANDO - history
**Para que serve:** Permite ver os ultimos comandos utilizados
**Exemplo:**
```bash
history
Ajuda para ver quais comando voce está utizando no dia a dia
```
## 14 COMANDO - find
**Para que serve:** Procura arquivos no sistema
**Exemplo:**
```bash
find . -name arquivo.txt
Esqueceu algum arquivo importante e não consegue achar ele uso esse comando 
```
## 15 COMANDO - whoami
**Para que serve:** Mostra o usuario atual
**Exemplo:**
```bash
whoami
Se voce divide computador isso ajuda a ver em qual perfil está sendo usado no momento
```
## 16 COMANDO - df
**Para que serve:** Mostra o uso do disco
**Exemplo:**
```bash
df -h
Se quiser verificar o uso de disco uso ele
```
## 17 COMANDO - rm
**Para que serve:** Remove arquivos
**Exemplo:**
```bash
rm arquivo.txt
Quer remover algum arquivo que foi usado ou não serve mais 
```
## 18 COMANDO - tail
**Para que serve:** Te leva até as ultimas linhas de um arquivo
**Exemplo:**
```bash
tail arquivo.txt
depois de usar o comando de ver o inicio quer verificar o final do arquivo use esse
```
## 19 COMANDO - cp
**Para que serve:** Copia arquivos
**Exemplo:**
```bash
cp arquivo.txt copia.txt
Quer ter duas copias daquele arquivo importante por segurança use esse comando
```
## 20 COMANDO - nano
**Para que serve:** Edita textos simples direto do terminal
**Exemplo:**
```bash
nano arquivo.txt
Está com preguiça de abrir o arquivo edite ele direto do terminal
```
## 21 COMANDO - ps
**Para que serve:** Mostra processos em execução
**Exemplo:**
```bash
ps aux
Quer saber o que está sendo executado
```
## 22 COMANDO - kill
**Para que serve:** Ele encerra processos
**Exemplo:**
```bash
kill 1234
Quer fechar algum processo que esteja sendo executado em segundo plano 
```
## 23 COMANDO - touch
**Para que serve:** Consegue criar arquivos vazios
**Exemplo:**
```bash
touch novo.txt
Quer começar um novo texto de algum trabalho, com um arquivo vazio 
```
## 24 COMANDO - du
**Para que serve:** Mostra o tamanho de arquivos e pastas
**Exemplo:**
```bash
du -h
Voce fez um TCC e precisa saber o tamanho desse arquivo use esse comando
```
## 25 COMANDO - chown
**Para que serve:** Muda o dono de um arquivo
**Exemplo:**
```bash
chown usuario arquivo.txt
Se voce divide o computador com seu irmão seria bom para o compartilhamento de arquivos 
```
## 26 COMANDO - echo
**Para que serve:** Exibe uma mensagem no terminal
**Exemplo:**
```bash
echo "Olá"
Basicamente é como se fosse o print no python 
```
## 27 COMANDO - man
**Para que serve:** Mostra o manual de algum comando
**Exemplo:**
```bash
man ls
Se tiver dificuldade com algum comando esse serve para ajudar
```
## 28 COMANDO - rmdir
**Para que serve:** Remove pastas vazias
**Exemplo:**
```bash
rmdir pasta
Precisa excluir pastas que estão vazias mais está com preguiça esse comando faz isso
```
## 29 COMANDO - vim
**Para que serve:** Consegue editar textos de forma mais avançada
**Exemplo:**
```bash
vim arquivo.txt
Precisa editar textos mais complicados esse ajuda
```
## 30 COMANDO -  ping
**Para que serve:** Testa a conexão entre o seu computador e outro endereço na rede (como um site).
**Exemplo:**
```bash
ping google.com
Ajuda a saber a latencia de uma conexão com um site
```
